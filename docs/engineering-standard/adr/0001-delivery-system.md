# ADR 0001: Nachvollziehbare KI-Entwicklung

Status: Bootstrap-Vorschlag. Ticket: pcgdevelop/robot-elevator-middleware#4.

Problem: Anforderungen, Dokumentation, Code und Abnahme müssen nachvollziehbar verbunden sein. Entscheidung: Repository-spezifisches Engineering-Board, echte Issues, Handbuch vor Code, nachvollziehbare Referenzen, kleine Umsetzung, unabhängiges Fachreview und risikobasierte Tests. Bestehende Regeln und Deploymentabläufe werden erhalten. Konsequenz: initiales Inventar und präzise Kriterien kosten Aufwand; Quellenfund allein ist keine Abnahme. Aktueller eigener Agentenzugang und technische Schreibgrenzen werden separat geprüft.
